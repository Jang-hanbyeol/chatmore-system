# Chatmore 브랜드 가이드라인

AI 기반 순천대학교 학생 맞춤형 생활정보 챗봇 **Chatmore**의 공식 브랜드 가이드입니다.

---

## 1. 브랜드 개요

- **브랜드명**: Chatmore (워드마크 표기: `chatmore`)
- **서비스 한글명**: AI 기반 순천대학교 학생 맞춤형 생활정보 챗봇
- **핵심 슬로건**: 흩어진 대학 정보를 하나의 대화로.
- **보조 슬로건**: 질문하면, 필요한 대학 정보를 더 빠르게.
- **브랜드 의미**
  - **Chat**: 복잡한 메뉴·검색 없이 자연스러운 대화로 정보를 찾는 경험
  - **More**: 하나의 질문에 답변 + 관련 공지·출처·추천 정보까지 더 많이 연결
  - **결합**: 질문하면 더 많은 대학 정보를 연결해 주는 AI 생활정보 서비스

## 2. 로고 콘셉트 제안 및 선정 과정

## Logo Concept 01
- 콘셉트명: 연결된 대화창 (Connected Bubbles)
- 핵심 형태: 두 개의 말풍선이 맞물리며 C·M 형태를 이루는 심볼
- 표현 의미: 사용자와 AI의 대화, 질문과 답변, 지속적인 정보 연결
- 사용 요소: 말풍선 2개, 연결 곡선
- 장점: 대화 서비스임이 직관적으로 전달, 브랜드 이니셜 내포
- 주의점: 두 말풍선의 결합이 작은 크기(16px)에서 뭉개져 식별이 어려움
- 추천 활용 위치: 큰 사이즈 히어로 그래픽

## Logo Concept 02
- 콘셉트명: 확장되는 정보 (Expanding More) — ★ 최종 선정
- 핵심 형태: 하나의 둥근 말풍선 안에서 점점 커지는 세 개의 점
- 표현 의미: 대화(말풍선) + 하나의 질문에서 확장되는 더 많은 정보(More),
  입력 중(typing) 모티프로 "실시간 응답"까지 암시
- 사용 요소: 라운드 사각 말풍선 + 꼬리, 크기가 증가하는 점 3개(evenodd 컷아웃)
- 장점: 단일 실루엣이라 16px 파비콘에서도 명확, 대화·확장·실시간이 한 형태에 담김
- 주의점: 점 크기 차이가 작으면 일반 채팅 아이콘과 구분이 약해짐 → 점 반지름을 4 / 5.25 / 6.75 로 명확히 차등
- 추천 활용 위치: 전 영역 (앱 아이콘, 파비콘, 챗봇 프로필, 헤더)

## Logo Concept 03
- 콘셉트명: AI 캠퍼스 네트워크 (Campus Nodes)
- 핵심 형태: 말풍선 내부에 책/건물을 단순화한 노드와 연결선
- 표현 의미: 대학 특화 서비스, 캠퍼스 정보 연결, 공식 정보 제공
- 사용 요소: 말풍선, 데이터 노드, 연결선
- 장점: "대학 정보" 정체성이 가장 강함
- 주의점: 요소가 많아 작은 크기에서 복잡, 회로 표현 지양 원칙과 충돌 위험
- 추천 활용 위치: 기술 소개 페이지 일러스트

## Final Direction
- 최종 선정안: Concept 02 — 확장되는 정보 (Expanding More)
- 선정 이유: ①작은 크기 식별성(파비콘·앱 아이콘) ②대화+확장이라는 브랜드 핵심 의미의 압축 ③과도한 AI 회로/로봇 표현 없이 친근하고 신뢰감 있는 인상 ④단색·반전에서도 형태 유지
- 적용 컬러: Chatmore Blue `#0052ff` 단일 브랜드 컬러 (Coinbase 디자인 시스템 재해석)
- 심볼 구조: viewBox 64×64, 라운드 사각 말풍선(rx16) + 좌하단 꼬리, 내부에 점 3개(r=4 → 5.25 → 6.75) evenodd 컷아웃
- 워드마크 구조: `chatmore` 소문자, Inter SemiBold 기반 벡터 패스(-1.2% 트래킹). 커스텀 요소: `more`의 **o 중앙에 데이터 노드 점**을 삽입해 심볼의 점 모티프와 연결
- 홈페이지 적용 방식: 밝은 헤더·푸터에는 블루 로고, 다크 히어로·CTA 밴드에는 화이트 반전 로고. 헤더는 데스크톱 가로형 / 모바일 심볼+축약 워드마크

## 3. 로고 시스템 구성

`/public/brand/` 에 포함된 파일:

| 파일 | 용도 |
|---|---|
| `chatmore-logo-primary.svg` | 기본 로고 (가로형과 동일) |
| `chatmore-logo-horizontal.svg` | 가로형: 헤더, 문서 상단 |
| `chatmore-logo-vertical.svg` | 세로형: 로그인 화면, 오류 페이지, 스플래시 |
| `chatmore-logo-symbol.svg` | 심볼 단독: 앱 아이콘, 파비콘, 챗봇 프로필 |
| `chatmore-symbol-white.svg` | 화이트 심볼: 블루/다크 배경 배지 |
| `chatmore-wordmark.svg` | 워드마크 단독: 좁은 영역, 문서 제목 |
| `chatmore-logo-korean.svg` | 한글 설명 포함형: 푸터, 공식 문서 |
| `chatmore-logo-white.svg` | 화이트 반전: 다크/블루 배경 |
| `chatmore-logo-black.svg` | 블랙 단색: 흑백 인쇄, 팩스 |
| `chatmore-symbol-512.png` / `-192.png` | 투명 배경 심볼 PNG |
| `favicon.svg`, `favicon-16/32/48.png` | 브라우저 파비콘 |
| `apple-touch-icon.png`, `icon-192/512.png` | 모바일 홈 화면·PWA 아이콘 (블루 플레이트) |
| `chatmore-og-image.png` | SNS 공유용 Open Graph (1200×630) |

모든 SVG는 폰트 의존성이 없는 **실제 벡터 패스**로 제작되었으며, 정확한 `viewBox` 를 갖고 16 / 24 / 32px 크기와 밝은·어두운 배경에서 식별성을 검증했습니다.

## 4. 컬러 시스템

홈페이지 디자인 토큰(DESIGNcoinbase.md 재해석)과 동일한 팔레트를 사용합니다.

| 이름 | HEX | 용도 |
|---|---|---|
| Chatmore Blue | `#0052ff` | 로고, 기본 CTA, 브랜드 액센트 (유일한 액션 컬러) |
| Blue Active | `#003ecc` | 버튼 프레스 상태 |
| Ink | `#0a0b0d` | 본문 제목, 흑백 로고, 다크 히어로 배경 |
| Body Gray | `#5b616e` | 본문 텍스트 |
| Surface Soft | `#f7f7f7` | 밝은 회색 밴드 |
| Surface Strong | `#eef0f3` | 보조 버튼, 배지 |
| White | `#ffffff` | 캔버스, 반전 로고 |
| Success | `#05b169` / Error `#cf202f` | 상태 표시 전용 (배경 사용 금지) |

- 로고는 **컬러(블루) / 블랙 / 화이트** 3가지 단색으로만 사용합니다.
- 컬러 위 로고: 블루·다크 배경 → 화이트 로고, 밝은 배경 → 블루 또는 블랙 로고.

## 5. 타이포그래피

- 한글: **Pretendard** (프로젝트에 가변 폰트 자체 호스팅)
- 영문 워드마크: Inter SemiBold 기반 (패스로 변환되어 폰트 설치 불필요)
- 디스플레이 타이틀은 weight 400 + 네거티브 트래킹, 본문은 400/600 사용

## 6. 보호 공간과 최소 크기

### 보호 공간
```text
최소 보호 공간 = 심볼 높이의 25%
```
로고 사방에 심볼 높이의 25% 이상 여백을 확보하고, 이 영역 안에 다른 그래픽·텍스트를 배치하지 않습니다.

### 최소 크기
```text
가로형 디지털 로고: 최소 너비 120px
워드마크 단독형: 최소 너비 90px
심볼 단독형: 최소 20px (파비콘 16px 은 전용 파일 사용)
인쇄용 가로형 로고: 최소 너비 30mm
```

## 7. 금지 사항

- 비율 임의 변경, 로고 회전
- 승인되지 않은 색상 사용 (블루/블랙/화이트 외)
- 과도한 그림자, 외곽선 임의 추가, 입체 효과·과도한 그라데이션
- 복잡한 사진 위에 대비 없이 배치
- 심볼과 워드마크의 위치·간격 임의 변경, 글자 간격 수정
- 저해상도 PNG 확대 사용 (SVG 원본 사용)
- **국립순천대학교 공식 로고와 결합·변형 금지** — Chatmore 로고와 대학 공식 로고는 항상 분리하여 사용하며, 대학 공식 브랜드로 오인될 수 있는 배치를 하지 않습니다.
